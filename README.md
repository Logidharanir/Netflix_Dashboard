# 🎬 Netflix Analytics Dashboard

## Project Description
The Netflix Analytics Dashboard is a data analysis project developed using Python, Pandas, Streamlit, and Matplotlib. It helps users explore and analyze Netflix content data through interactive visualizations, key performance indicators (KPIs), and filters. The project uses synthetic practice data and does not represent actual Netflix business data.

## Features
- **KPI Analysis:** Displays total content, views, watch hours, and estimated revenue.
- **Monthly Content Trend:** Analyzes content added over time.
- **Content Type Analysis:** Compares views between movies and TV shows.
- **Top 10 Content:** Identifies the most-viewed content titles.
- **Genre Analysis:** Shows views across different genres.
- **Country Analysis:** Identifies the top 10 countries based on views.
- **Rating Distribution:** Visualizes content ratings using a pie chart.
- **Release Year Analysis:** Examines content distribution by release year.
- **Interactive Filters:** Filter data by date range, genre, country, and content type.
- **Data Export:** View filtered records and download them as a CSV file.

## Technologies Used
- Python
- Pandas
- Streamlit
- Matplotlib

## Installation and Usage
1. Clone the repository from GitHub.
2. Install the required Python libraries using `pip install pandas streamlit matplotlib openpyxl`.
3. Ensure the dataset is available in the project folder.
4. Run the application using `streamlit run app.py`.
5. Explore the dashboard using the available filters and visualizations.

## Project Objective
The main objective of this project is to practice data cleaning, data filtering, aggregation, exploratory data analysis, and data visualization. It provides a simple way to understand content performance, identify popular genres and countries, compare content types, and analyze viewing trends.
